# Vani Tuition Centre System – Documents Repository

## Purpose

This repository contains all official project documentation related to the Vani Tuition Centre Admin Portal and Website System.

It is used to manage software engineering documents, reports, diagrams, and project records throughout the System Design Project lifecycle.

---

## Repository Structure

```plaintext
documents/
│
├── SRS/
├── SDS/
├── Meeting-Notes/
├── Pitch-Deck/
├── Log-Forms/
└── Diagrams/
```

## Included Documents

- Software Requirements Specification (SRS)
- Software Design Specification (SDS)
- Meeting Notes

- Weekly Log Forms

## Branch Strategy

| Branch | Purpose |
|--------|---------|
| `main` | Approved documents only |
| `draft/<document-name>` | Working draft branches |
| `fix/<issue-number>` | Corrections and review fixes |

---

## Contribution Guidelines

Before contributing:

- Follow the branch naming strategy
- Use proper commit message conventions
- Ensure formatting consistency
- Review documents before creating Pull Requests

Please refer to `CONTRIBUTING.md` for complete contribution rules.

---

## Team Workflow

1. Pull latest repository updates
2. Create a draft branch
3. Make document changes
4. Commit changes properly
5. Push branch to GitHub
6. Create a Pull Request
7. Receive approval
8. Merge into `main`

---

## Main Branch Protection Rules

The `main` branch is protected with the following rules:

- Direct commits are prohibited
- Pull Requests are mandatory
- Minimum one approval required
- Review comments must be resolved before merge

---

## Documentation Standards

All documents should:

- Follow the official report template
- Use clear section headings
- Maintain consistent formatting
- Include references where necessary
- Be proofread before submission
